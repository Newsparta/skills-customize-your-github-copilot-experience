# 📘 Assignment: File Handling and JSON

## 🎯 Objective

Learn how to read from and write to files in Python, especially JSON files, so your programs can store and reuse data across runs.

## 📝 Tasks

### 🛠️ Save Data to a JSON File

#### Description
Create a small program that stores a list of student names or tasks in a JSON file.

#### Requirements
Completed program should:

- Define a Python list or dictionary of data
- Write the data to a JSON file using the `json` module
- Save the file in a clear and readable format
- Open the file after writing to confirm the saved content is valid JSON

### 🛠️ Read Data from a JSON File

#### Description
Build a program that loads data from a JSON file and displays it in a clear way.

#### Requirements
Completed program should:

- Read a JSON file using Python
- Convert the file contents into Python data structures
- Print or display the data in a readable format
- Handle a missing or invalid file gracefully with a helpful message

### 🛠️ Update and Reuse Stored Information

#### Description
Create a program that adds new information to an existing JSON file and then reads it back.

#### Requirements
Completed program should:

- Load existing JSON data before making changes
- Add new entries or update values in the data structure
- Write the updated data back to the same file
- Demonstrate the program working with at least one example input
